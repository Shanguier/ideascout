# Security

IdeaScout's reference script is offline. It does not open a network connection,
read credentials, or execute a topic string as code.

## Reporting

If you find a vulnerability in this repository, open a private security advisory
on GitHub (Security → Report a vulnerability). Use a public issue only when the
report is not sensitive.

Please do not file secrets, tokens, or personal data in issues or pull requests.

## Supported surface

The maintained surface is the current `main` branch of
<https://github.com/Shanguier/ideascout>. There is no hosted service attached to
this repository.
